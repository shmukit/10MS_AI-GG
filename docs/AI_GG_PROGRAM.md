# AI-Enabled Group Guidance (AI-GG) Program

## Overview
The AI-GG program is a comprehensive learning platform designed to provide structured, AI-powered guidance for students in group learning environments. It combines personalized roadmaps with collaborative learning through external communication channels.

## Core Features

### 🗺️ AI-Powered Roadmap System
- **Structured Learning Paths**: Pre-defined roadmaps for various programming languages and technologies
- **Adaptive Progression**: AI suggests next steps based on student performance
- **Week-by-Week Breakdown**: Organized learning modules with clear milestones
- **Task Variety**: Mix of videos, readings, projects, and assessments
- **Instructor slides**: Optional PDF/Google Slides URL per roadmap — [ROADMAP_SLIDES.md](./ROADMAP_SLIDES.md)
- **Workshop tools**: Embedded decision tree for AI pattern selection on workshop roadmaps

### 👥 Group Learning Management
- **Batch Organization**: Students grouped into learning cohorts
- **Mentor Assignment**: Experienced professionals guide each batch
- **Progress Tracking**: Real-time monitoring of individual and batch progress
- **Collaborative Environment**: External community through WhatsApp and Discord

### 🎯 Smart Task Management
- **AI-Generated Tasks**: Personalized assignments based on learning pace
- **Progress Monitoring**: Track completion status and performance metrics
- **Deadline Management**: Structured timeline for learning objectives
- **Feedback System**: Mentor input on student submissions

### 📢 Communication Hub
- **Notice Board**: Important announcements and updates
- **External Channels**: WhatsApp groups for batch discussions
- **Discord Server**: Platform-wide community and support
- **Emergency Contacts**: Direct mentor communication when needed

## User Roles

### Student
- Access personalized learning roadmaps
- Complete assigned tasks and projects
- Track progress through visual dashboards
- Connect with batch members via external channels
- Receive AI-suggested learning paths

### Mentor (Admin Functions)
- Create and manage learning roadmaps
- Organize student batches
- Monitor individual and batch progress
- Send notices and announcements
- Manage WhatsApp/Discord group links
- Provide feedback on student work

## Technology Stack
- **Frontend**: React with TypeScript
- **Styling**: Tailwind CSS
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **External Integration**: WhatsApp Business API, Discord Bot API

## Learning Approach
1. **Structured Progression**: Clear learning milestones
2. **AI Guidance**: Personalized recommendations
3. **Group Collaboration**: Peer learning through external channels
4. **Mentor Oversight**: Professional guidance and feedback
5. **Practical Application**: Project-based learning with real-world scenarios

## Target Outcomes
- **Skill Development**: Practical programming and technical skills
- **Community Building**: Strong peer networks through external platforms
- **Career Readiness**: Industry-relevant project experience
- **Mentor Relationships**: Professional guidance and networking
- **Self-Directed Learning**: AI-powered personalized education paths
